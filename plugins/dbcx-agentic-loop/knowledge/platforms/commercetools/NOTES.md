# commercetools pack notes

- **Roles = `["target"]` only, and no `as_source` block.** commercetools is multi-tenant SaaS whose extension model is API Extensions, Subscriptions, Merchant Center Custom Applications and Connect connectors. There is no shop code base on the platform side to inventory; whatever code a client has is their own frontend and middleware, not a commercetools repository.
- **No `adapter.py`** (nothing to scan).
- **"No CMS" is stated three times on purpose** - in `_readme`, in `as_target.snippets.content_model_notes`, and as a bold lead paragraph in `research-seed.md` - because it is the single fact that most changes a fit estimation. `content_model_name` is therefore "content component (external CMS)" / "Content-Komponente (externes CMS)", and `target_content_component_types` names the platform primitives that DO exist (localized fields, Assets, Type-based custom fields, CustomObjects, Product Selections) separately from the external-CMS component types a project must supply.
- **The other three "missing UI" facts** - no order-management UI, no search-merchandising UI, no CSR/impersonation tooling - sit in `expected_hotspots_d3` and `expected_blockers_d4`. A capability that exists on the API but has no Merchant Center screen is NOT covered for a business user, and `critic2_focus` says so explicitly.
- **Write and read contracts are called out** because they are the recurring migration cost: update actions with version + 409 optimistic concurrency on every write, and eventually consistent product projections / Product Search on every listing read.
- **Not established here** and marked `*(verify)*`: the current region list and data-residency options; the per-project limits and quotas; the GA status and scope of the Product Search API and any search merchandising; the current scope of commercetools Frontend and commercetools Checkout as separate products; the Approval Rules expression language; API Extension timeouts and Subscription retry semantics; and the current Merchant Center feature set, which is the one part of the "missing UI" picture that genuinely moves.
- Product names shift (Frontastic to commercetools Frontend) - `docs_domains` warns the researcher not to cite a remembered product name.
