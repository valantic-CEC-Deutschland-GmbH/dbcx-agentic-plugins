# sap-emarsys pack notes

Built from official documentation only (no client material). Last verified: **2026-10-05**.

- **Product and naming.** help.sap.com (product `SAP_EMARSYS`, version `CLOUD`) and the Feature Scope Description call the product "SAP Engagement Cloud | SAP Emarsys" (short "SAP Emarsys"); dev.emarsys.com still says "SAP Emarsys Customer Engagement Platform". `display` follows help.sap.com; `aliases` in pack.json lists the other names. Since 2025-10-30 Automation Center = "Audience-based Automation" and Interactions = "Event-based Automation"; many pages still use the old names.
- **Role = target only**, no `as_source`, no `adapter.py`: SaaS without a client code base. Use: tech-fit-estimation `--knowledge platform=sap-emarsys` (brownfield: the client already runs one account and adds countries, brands, channels and triggered journeys) and the standard critic `standard-sap-emarsys`.
- **Files.** `pack.json` (as_target snippets incl. `critic2_persona`, `docs_domains`, `best_practice`, `critic2_focus`, `expected_hotspots_d3`, `expected_blockers_d4`, `content_model_notes`, `api_families_hint`, `effort_rules` with the triggered-journey and new-account estimation pattern); `knowledge.json` (target_* keys only - a target pack contributes nothing else to `dbcx knowledge show`: API endpoint families, content / message types, `target_estimation_patterns`, `target_multi_account_options`, `target_standard_vs_config_vs_extension`); `reference-cache.md` (365 verified rows with verbatim quotes, grouped by topic); `research-seed.md` (*(verify)* items and pointers to verified rows); `labels.<lang>.json`.
- **Sources.** 342 rows from help.sap.com (Application Help 179, Getting Started 72, Support Center 45, Integration Guide 38, Feature Scope Description 8) and 23 rows from dev.emarsys.com. Every quote was checked against the page text. help.emarsys.com is bot-protected and was not used.
- **Coverage.** Naming / packaging, environments (provisioning, sandbox, test tenants, demo tenants, account deletion), multi-account distribution, contact data model and fields, consent / DOI, Event-based and Audience-based Automation, triggers (External Events, Engagement Events, connector events, Web Extend, Product Catalog Updates, Wishlist), testing, segments, channels (email, mobile, web, SMS, conversational, wallet, vouchers), content (VCE, templates, Brand Center), personalization, Predict / Recommendation Center / product catalog, sales data / Smart Insight, Loyalty (context), integrations (SAP Commerce Cloud, CDC, CDP, Relational Data, Universal Schema Builder, exports), B2B, API and limits, roles / security, deliverability, data residency, deprecations, pitfalls.
- **Findings that change estimates most.** (1) External Events only for clients who started before January 2026, and the External event trigger source is deprecated from Q2 2026 - new journeys and new accounts belong on Engagement Events (existing contacts only, 200 kB, 5000 calls / min). (2) Event-based Automation sends via Triggered Email, which ignores opt-in. (3) The SAP Commerce Cloud connector: one Backoffice per Emarsys account, fixed customerID identifier and mapping, logged-in users only, products in one language and one currency. (4) Distribution copies programs and some content, not the account set-up (domains, DNS, ramp-up, users, connectors, Predict / Web Extend, contact lists, relational segments, API nodes). (5) Sandbox / test tenants cannot send email. (6) Brand Center, Design Themes, Universal Schema Builder and Localized Product Personalization were Early Adopter / Pilot. (7) WSSE API authentication sunset.
- **Conflicts between official pages (kept as separate rows).** WSSE sunset "end of 2026" vs EOL "February 1, 2027"; external-event payload 1 MB (current pages) vs 500 KB (2023 changelog entry); contacts per API call 1000 (developer hub) vs "batches of up to 10,000" (Getting Started); Web Extend first-party cookie 7 days vs one year; Salesforce Commerce Cloud connector on the Strategic Platform Integrations page but not in the Feature Scope Description; Engagement Event contact-match retry "4 times" vs a table with 3 retries; ABA "Finished" reactivation rules differ between two pages (only the statuses-page row is kept).
- **Gaps (stay *(verify)* in the seed).** Hosting location of the core platform / data-centre choice; package-to-feature (SKU) mapping; whether a new account of a pre-2026 client gets External Events; Sandbox vs Testing Tenant vs "Core + Test tenant"; distributability of Engagement-Event programs, forms, voucher pools and Relational Data connections; prepackaged SAP Integration Suite content (none found on the Emarsys pages); current GA status of the Pilot / Early Adopter features; pricing (SMS credits, dedicated IPs).
- **Refresh.** GA states and deprecations move with every quarterly release ("What's New in SAP Emarsys"; the old changelog page is archived on 2026-12-31). Re-verify rows older than two releases; the help.sap.com topic URLs carry `version=CLOUD` (always the latest).
