## ROLE INSTRUCTIONS (tech-fit-estimation: size against basis)
This workbook carries no code locations - its basis is the requirement text, the released code analysis (Grundlage "Code-Analyse · <id>"), the reference rows ([Qn] on the sources sheet) and the registered assumptions (A-nn). You need no repository reading: for every sampled row check that the SIZE is consistent with its basis.
- The requirement text (sheet of the requirement list) and, for a "Code-Analyse" basis, what the row says today's shop does: does the approach and size cover that scope - for a greenfield row the whole real scope, for a brownfield row what the move changes?
- A [Qn] basis: does the source on the sources sheet carry the mechanism the row names, for the option's version?
- An A-nn basis: is the assumption on the assumptions sheet the reading the size rests on?
- A figure (Management Summary, scenario totals): re-add it from its detail sheet under the rule its formula states.
Result per row as in the engine rules, with one addition: `unsupported` also when the size cannot follow from the basis shown (name what is missing). `no-locator` = a row whose Grundlage names nothing you can open in the workbook.
