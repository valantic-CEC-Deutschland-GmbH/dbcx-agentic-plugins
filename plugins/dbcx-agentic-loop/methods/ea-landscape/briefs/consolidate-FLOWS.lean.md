**Flows.** One row per DIRECTED flow, ids `F-001..` and stable once given. Read every document the digest lists for each system (the inventory's `interfaces_mentioned` is an upper bound, not a count you copy): an interface exists when a document's TEXT says data moves between two systems - name the mechanism, the frequency and the data objects the text gives. **SSOT matrix.** One row per data object of the inventory - every one of them, including those no system claims. `verdict`:
- `single-master` - exactly one system is claimed as master and no document contradicts it; `master_system` names it.

- `unknown` - no document names a system of record. `master_system` is `-`. This is a finding about the client's documentation, not about your work.
Never derive mastership from an interface direction alone: a system that receives an object nightly and writes into it is a `copy`.
